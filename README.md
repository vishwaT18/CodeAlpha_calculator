🧮 Advanced Calculator Web Application
📌 Project Overview

The Advanced Calculator is a responsive web application developed using HTML, CSS, and JavaScript. It performs basic arithmetic calculations and includes additional features such as calculation history, keyboard support, delete functionality, and a modern glassmorphism user interface.

This project was created to improve front-end development skills and demonstrate JavaScript DOM manipulation and event handling.
